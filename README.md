## 📌 Project Overview

**Study Buddy** is an interactive study dashboard built with **Python and Streamlit** that brings multiple study tools into one personalized workspace.

Instead of switching between different applications for notes, tasks, revision, quizzes, focus sessions and study materials, Study Buddy provides these features within a single interface.

The application combines:

- 🤖 AI-powered study assistance
- 📝 Notes and PDF-based learning
- 📋 Task management
- 🎯 Focus sessions
- 🧠 Flashcards
- ❓ AI-generated quizzes
- 🗺️ Mind maps
- 🎧 Study podcast / text-to-speech
- 🎮 Learning games
- 📊 Progress tracking
- 🔐 User accounts and authentication

The goal is to create a calm, personalized environment that helps students move from **learning → practicing → revising → tracking progress**.

# ✨ Features

## 🏠 1. Personalized Dashboard

The dashboard acts as the central workspace for the student's study activity.

It provides an overview of:

- Current tasks
- Upcoming deadlines
- Recent notes
- Study activity
- Progress
- Quick access to study tools

The interface uses a calm green and ivory visual theme designed to reduce visual clutter.

---

## 📝 2. Notes

Study Buddy allows users to create and manage study notes directly inside the application.

Users can:

- Create notes
- Edit notes
- Delete notes
- Pin important notes
- Organize notes by subject
- Assign different note colors
- Search and access recent material

The application can also create notes from imported PDF material.
